# Sample Markdown Output

This is an example of what `web-markdown-dl` produces when converting a webpage to Markdown.

## How it works

The tool uses **Playwright** to fetch the page, **Mozilla Readability** to extract the main content (removing ads and navigation), and **Turndown** to convert the HTML to clean Markdown.

### Key Benefits

1. **Clean Content**: Only the article or main page content is preserved.
2. **Standard Markdown**: Uses GitHub Flavored Markdown (GFM).
3. **Preserved Formatting**: Tables, links, and code blocks are kept intact.

| Feature | Support |
|---------|---------|
| Tables  | Yes     |
| Images  | Yes     |
| Code    | Yes     |
